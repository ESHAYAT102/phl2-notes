## What This Module Covers

Seed an administrator, paginate query results, fetch posts by ID, increment views, and group related writes in a transaction.

## Lessons

- [Admin Seeding Part 1 and 2](./m26-1)
- [Creating Pagination](./m26-3)
- [Get Post by ID and Increment View Count and Transaction](./m26-9)

## Learning Goal

By the end of this module, you should be able to implement pagination and use a transaction when multiple database changes must succeed together.
