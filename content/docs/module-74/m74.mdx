DTO stands for **data transfer object**. Separate request and response DTOs keep
the API contract independent from the database model.

---

The completed code is available in the [GoTickets repository](https://github.com/Apollo-Level2-Web-Dev/gotickets/tree/part-2).

Move the `main.go` file out of the `cmd` folder and delete the empty `cmd` folder,
then run the application from the project root with `go run main.go`.
