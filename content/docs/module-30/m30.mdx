The previous modules built a blog API with Prisma, Express, and PostgreSQL,
including endpoints to create, read, update, and delete posts.

This module connects that API to a Next.js frontend. It covers fetching and
displaying posts, sending mutations, handling loading and error states, and
keeping the client UI consistent with the backend data.
