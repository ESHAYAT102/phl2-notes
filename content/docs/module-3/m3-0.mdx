## What This Module Covers

Learn how stateful data structures work by implementing stacks, queues, and linked lists in JavaScript. The lessons move from class basics to the operations that make each structure useful.

- [Queue Implementation using Array](./m3-4)
- [Linked-list: a Visual Representation](./m3-5)
- [Linked List Implementation: Basic Concept of Node](./m3-6)
- [Linked List Implementation: Append() and Print()](./m3-7)
- [Linked List Implementation: Prepend()](./m3-8)
- [Linked List Implementation: Insert()](./m3-9)
- [Linked List Implementation: Remove()](./m3-10)
- [Queue Implementation with Linked List](./m3-11)

## Learning Goal

By the end of this module, you should be able to explain the trade-offs between stacks, queues, arrays, and linked lists; then implement their core operations.
