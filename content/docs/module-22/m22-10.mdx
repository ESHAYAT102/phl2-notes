---
title: "Upsert in Prisma (Update and Delete)"
description: "Lesson 22.10: Upsert in Prisma (Update and Delete)."
---

Use `upsert` to create a data if it doesn't exist or update it if it already exists.
Takes the `update` key to receive the data that needs to be updated, and the `create` key takes in the keys that needs to be created if the data doesn't exist. Must use the `where` key to find the dedicated data.
