## What This Module Covers

Prepare a TypeScript Express application for deployment by compiling it to JavaScript, configuring production commands, and troubleshooting build errors.

## Lessons

- [Build and Deploy Your Express and TypeScript APP](./m13-5-1)
- [How You Should Solve Your Errors Before Deploying Your App](./m13-5-2)

## Learning Goal

By the end of this module, you should be able to produce and run a deployable JavaScript build of an Express application.
