Scope determines where a declared name can be used. Go has package, file, function,
and block scopes.

## Package and Local Scope

A package-level variable is available throughout its package. A local variable is
available only inside the function or block where it is declared.

```go
package main

import "fmt"

var application = "notes" // package scope

func main() {
	message := "hello" // function scope
	if ready := true; ready {
		fmt.Println(application, message, ready)
	}
	// ready is not available here
}
```

## Closures

An inner function can capture variables from its surrounding scope:

```go
count := 0
increment := func() {
	count++
}
increment()
fmt.Println(count) // 1
```

The captured variable remains shared with the closure; it is not copied for each
call.

## Shadowing

An inner declaration may reuse an outer name. This is called shadowing, and the
outer value becomes temporarily inaccessible. Keep scopes small and avoid
accidental shadowing, particularly when using `:=` with `err`.
