## What a Data Type Does

A type tells Go:

- What kind of data a variable holds
- How much memory to allocate
- What operations are allowed

## Common Built-In Types

### Integers

- Signed: `int`, `int8`, `int16`, `int32`, `int64`
- Unsigned: `uint`, `uint8`, `uint16`, `uint32`, `uint64`, `uintptr`
- Aliases: `byte` is `uint8`; `rune` is `int32`

Use `int` for ordinary counts and indexes. Use a fixed-width type for binary
formats or protocols that require an exact size. Unsigned integers include zero;
they are not simply “positive integers.”

### Floating-Point and Complex Numbers

- `float32`, `float64`
- `complex64`, `complex128`

Go has no type named `float`; use `float64` unless a specific size is required.
Floating-point values are approximate, so do not use them for exact currency.

### Booleans and Strings

- `bool` stores `true` or `false`.
- `string` stores an immutable sequence of bytes, conventionally UTF-8 text.

Indexing a string returns a byte. Use `for range` when iterating over Unicode
code points (`rune` values).

## Type Inference and Conversion

Go infers a type from an initializer, but it does not perform implicit numeric
conversions:

```go
count := 3        // int
ratio := 0.5      // float64
total := float64(count) * ratio
```

Conversions are explicit because different numeric types can have different
ranges and precision.

## Composite Types

Arrays, slices, maps, structs, pointers, functions, interfaces, and channels are
also types. Their behavior—such as whether they are comparable or have a `nil`
value—depends on the specific type.
