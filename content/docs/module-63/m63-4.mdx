Go offers several forms of variable declaration. Choose the form that makes the
type and initial value easiest to understand.

## Declaration Forms

Use `var` with an explicit type when the zero value is useful or the type is not
obvious:

```go
var name string // ""
var attempts int // 0
```

Assign a value in the declaration and Go can infer its type:

```go
var language = "Go" // string
var version = 1.25  // float64
```

Inside a function, `:=` is the usual short declaration form:

```go
func main() {
	message := "Hello, Go"
	fmt.Println(message)
}
```

`:=` cannot be used at package scope. Within the same scope, it must declare at
least one new variable.

## Multiple and Grouped Variables

```go
var x, y int
name, age := "Eshayat", 16

var (
	host = "localhost"
	port = 8080
)

x, y = y, x // swap values without a temporary variable
```

## Reassignment and Shadowing

Use `=` to update an existing variable. A declaration in an inner block can
shadow a variable with the same name, creating a different variable:

```go
count := 1
if ready := true; ready {
	count := 2 // shadows the outer count
	fmt.Println(count)
}
fmt.Println(count) // 1
```

Shadowing is legal but can hide mistakes, especially with `err` variables.

## Naming Rules and Conventions

- Names are case-sensitive and cannot start with a digit.
- Go convention uses short `camelCase` or `PascalCase` names, not underscores.
- A package-level name beginning with an uppercase letter is exported.
- Use `_`, the blank identifier, when a returned value is intentionally ignored.
