## Multiple Variables

Variables with the same type can share a declaration:

```go
var width, height int
var start, end = 1958, 2009
name, active := "Gopher", true
```

Multiple assignment evaluates the right-hand side before updating the variables,
which makes swaps straightforward:

```go
left, right = right, left
```

## Constants

A constant is a compile-time value that cannot be reassigned. Constants can be
strings, numbers, booleans, or expressions composed from other constants.

```go
const pi = 3.14159       // untyped constant
const timeout = 30       // can be used with compatible numeric types
const appName string = "Notes"
```

Constants have no `:=` form and cannot be initialized from a runtime result such
as `time.Now()`.

### Groups and `iota`

Use a constant group with `iota` for related sequential values:

```go
type Status int

const (
	StatusPending Status = iota
	StatusRunning
	StatusDone
)
```

Use `iota` when the numeric values are implementation details. Use explicit
values when they are part of a database, file, or network contract.
