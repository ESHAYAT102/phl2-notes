Functions declare their parameter types after the parameter names. Parameters of
the same type can share a type declaration:

```go
package main

import "fmt"

func makeCoffee(kind, size string) {
	fmt.Printf("Making a %s %s coffee...\n", size, kind)
}

func main() {
	makeCoffee("Americano", "large")
}
```

Arguments are passed by value: a function receives a copy of each argument.
Slices, maps, pointers, and channels contain references to underlying data, so a
function may still affect that shared data.

Small functions should usually do one clear job. Go does not support default or
named arguments; use a struct when a function needs many related options.
