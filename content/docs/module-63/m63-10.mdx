Go functions can return more than one value. The most common pattern is a result
plus an `error`.

```go
package main

import "fmt"

func coffee(kind string, price int) (string, int) {
	return fmt.Sprintf("%s coffee", kind), price
}

func main() {
	drink, price := coffee("Americano", 250)
	fmt.Printf("%s costs %d taka\n", drink, price)
}
```

Use `_` to ignore a value intentionally:

```go
drink, _ := coffee("Americano", 250)
```

## Named Results

Names in the result list create variables initialized to their zero values:

```go
package main

import "fmt"

func coffee(kind string) (drink string, price int) {
	drink = fmt.Sprintf("%s coffee", kind)
	price = 250
	return
}

func main() {
	drink, price := coffee("Americano")
	fmt.Printf("%s costs %d taka\n", drink, price)
}
```

Named results can clarify short functions or documentation, but bare `return`
statements become difficult to follow in long functions. Prefer explicit returns
when they make the control flow clearer.
