## Zero Values

A declared variable that has no initializer receives the zero value for its type.
This lets useful types work without a constructor.

| Type | Zero value |
| --- | --- |
| Numbers | `0` |
| `bool` | `false` |
| `string` | `""` |
| Pointers, slices, maps, functions, interfaces, channels | `nil` |
| Arrays and structs | Each field or element receives its zero value |

A nil slice can be read, ranged over, and appended to. A nil map can be read but
must be initialized with `make` before writing.

## Formatting with `fmt`

| Verb | Output |
| --- | --- |
| `%v` | Default representation |
| `%+v` | Field names when printing a struct |
| `%#v` | Go-syntax representation |
| `%T` | Value's type |
| `%t` | Boolean |
| `%s`, `%q` | String; quoted string |
| `%d`, `%b`, `%o`, `%x`, `%X` | Integer in decimal, binary, octal, or hexadecimal |
| `%f`, `%e`, `%g` | Floating-point formats |
| `%c`, `%U` | Character and Unicode format |
| `%p` | Pointer address |
| `%%` | Literal percent sign |

Width and precision refine a verb: `%8d` pads an integer to eight characters and
`%.2f` prints two digits after the decimal point.

```go
name, score := "Ari", 91.456
fmt.Printf("%s scored %.2f (%T)\n", name, score, score)
```

Use `fmt.Print` or `fmt.Println` for direct output. Use `fmt.Sprintf` to return a
formatted string. `%w` is specific to `fmt.Errorf` and wraps an error for
`errors.Is` and `errors.As`.
