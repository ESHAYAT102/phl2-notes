---

A return type appears after the parameter list. Every path through a function
with a return type must return a compatible value.

```go
package main

import "fmt"

func coffee(kind string) string {
	return fmt.Sprintf("%s coffee", kind)
}

func main() {
	drink := coffee("Americano")
	fmt.Println("I'm having", drink)
}
```

Go commonly returns an `error` alongside a result when an operation can fail:

```go
func percentage(part, total float64) (float64, error) {
	if total == 0 {
		return 0, errors.New("total must not be zero")
	}
	return part / total * 100, nil
}
```

Handle the error before using the result. Reserve `panic` for conditions the
current code cannot reasonably recover from.
