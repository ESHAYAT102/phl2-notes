---
title: "LIKE vs ILIKE"
description: "Lesson 18.7: LIKE vs ILIKE."
---

LIKE is used for selecting values with the similar characteristics.

- `%` - there might be any characters
- Any character - the values with the specific character(s)
- `_` - has the fixed number of characters as the underscores (giving 5 underscores mean there are 5 characters in the value)
