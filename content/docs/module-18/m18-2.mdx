---
title: "ALTER Default Values and Column Constraints"
description: "Lesson 18.2: ALTER Default Values and Column Constraints."
---

Set default value:

```
alter table users
alter column email set default 'test@mail.com'
```

Add constraint:

```
alter table users add constraint unique_users_email unique(email)
```

Drop constraint:

```
alter table users drop constraint unique_users_email
```
