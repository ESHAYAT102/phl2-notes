# Big O Notation

Big O notation describes how an algorithm's resource use grows as its input
size grows. It is commonly used for:

- **Time complexity:** How the number of operations grows
- **Space complexity:** How additional memory use grows

Common complexity classes include:

- O(n)
- O(n²)
- O(log n)
- O(n log n)
- O(1)

## Basic complexity classes

- **O(1), constant:** Work does not grow with the input size, such as reading an array element by index.
- **O(log n), logarithmic:** Work grows slowly because each step discards a fixed fraction of the remaining input, as in binary search.
- **O(n), linear:** Work grows in direct proportion to the input size, as in scanning an array once.
- **O(n log n), linearithmic:** Common in efficient comparison-based sorting algorithms.
- **O(n²), quadratic:** Work grows with the square of the input size, often because of nested loops over the same data.
