# Comparing Time Complexities

Complexity analysis often considers the worst case because it provides an upper
bound on the work an algorithm may perform. Best-case and average-case behavior
can also matter, depending on the application.

Array methods do not all have the same complexity. Methods that scan the array,
such as `find`, `map`, and `filter`, are O(n). Indexed access and `push` are
typically O(1), while operations that shift existing elements are O(n).
