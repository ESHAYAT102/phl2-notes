# Data Flow

Planning the data flow before implementation makes the work easier to reason about.

- **Top-down approach:** Define the goal, then identify the steps needed to reach it.
- **Decomposition:** Split the work into small, independent tasks.

## Idea of critical thinking

Define these three parts before writing code:

- Input
- Process
- Output

Start with the expected output, determine the required input, and then define the transformation step by step.

Three concepts help you evaluate and improve that process:

- Data structures
- Algorithms
- Big O notation
