# Data Structures

## Common JavaScript data structures

JavaScript includes several built-in ways to organize data:

- Array
- Object
- Set
- Map

## Why data structures matter

Each structure supports a different access pattern. Arrays are useful for ordered
collections, objects and maps associate keys with values, and sets store unique
values. Choosing the right structure makes code clearer and can improve its
performance.
