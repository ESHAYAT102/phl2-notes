# What Is an Algorithm?

An algorithm is a finite, well-defined sequence of steps for solving a class of
problems. A function is a unit of code; it may implement an algorithm, but the
two terms are not interchangeable.

An algorithm should:

- Accept zero or more inputs
- Produce an output
- Define each step unambiguously
- Finish after a finite number of steps

## Choosing an algorithm

One problem can have several valid algorithms. The best choice depends on the
requirements: correctness, execution time, memory use, implementation complexity,
and any domain-specific constraints.
