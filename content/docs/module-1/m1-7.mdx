# Array Operation Complexity

A loop over every array element is O(n): its work grows linearly with the array.

These end-of-array operations are typically O(1):

- `push`
- `pop`

Reading an element by index is also O(1). By contrast, `shift`, `unshift`, and
inserting near the beginning are O(n) because the remaining elements must move.
