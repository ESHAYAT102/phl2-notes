# Set

Create a set with `new Set()`:

```js
const mySet = new Set();
```

## Adding values to a set

Use the `add` method to add an element to the set:

```js
const mySet = new Set();

mySet.add("apple"); // [!code highlight]
```

You can use `size` to check the size of the set:

```js tab="code"
const mySet = new Set();

mySet.add("apple");

console.log(mySet.size); // [!code highlight]
```

```bash tab="result"
1
```

A `Set` stores each value only once:

```js tab="code"
const mySet = new Set();

mySet.add("apple"); // [!code highlight]
mySet.add("mango");
mySet.add("banana");
mySet.add("apple"); // [!code highlight]

console.log(mySet);
```

```js tab="result"
Set(3) {
  "apple", // [!code highlight]
  "mango",
  "banana",
}
```

The duplicate `apple` value appears only once.

## Creating a set from an array

Passing an array to the constructor creates a set containing its unique values:

```js tab="code"
const arr = ["apple", "mango", "banana", "apple"];

const mySet = new Set(arr); // [!code highlight]

console.log(mySet);
```

```bash tab="result"
Set(3) {
  "apple",
  "mango",
  "banana",
}
```

## Iterating over a set

Use `forEach` or a `for...of` loop to iterate over a set.

## Creating an array from a set

Use `Array.from()` or the spread operator to convert a set to an array:

```js tab="code"
const mySet = new Set();

mySet.add("apple");
mySet.add("mango");
mySet.add("banana");
mySet.add("apple");

const arr = Array.from(mySet); // [!code highlight]

console.log(arr);
```

```bash tab="result"
[ "apple", "mango", "banana" ]
```

The resulting array contains no duplicates.

## `has` method for sets

The `has` method checks whether a set contains a value:

```js tab="code"
const mySet = new Set();

mySet.add("apple");
mySet.add("mango");
mySet.add("banana");
mySet.add("apple");

console.log(mySet.has("tomato")); // [!code highlight]
```

```bash tab="result"
false
```

The result is `false` because the set does not contain `tomato`.

## `delete` method for sets

The `delete` method removes a value from a set:

```js tab="code"
const mySet = new Set();

mySet.add("apple");
mySet.add("mango");
mySet.add("banana");
mySet.add("apple");

mySet.delete("banana");

console.log(mySet); // [!code highlight]
```

```js tab="result"
Set(3) {
  "apple",
  "mango",
}
```

# Array

## Removing duplicates from an array

The simplest way to remove duplicates from an array is:

```js tab="code"
const arr = ["apple", "mango", "banana", "apple"];

const removeDuplicates = (arr) => {
  const set = new Set(arr);

  return Array.from(set);
};

console.log(removeDuplicates(arr));
```

```bash tab="result"
[ "apple", "mango", "banana" ]
```
