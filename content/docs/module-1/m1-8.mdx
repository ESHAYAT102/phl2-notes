# Measuring Execution Time

Timing a function can help compare implementations, although a single result is
not a substitute for a proper benchmark.

### `performance.now()` approach

Use `performance.now()` to measure elapsed time with a high-resolution timer:

```js
const startTime = performance.now(); // [!code highlight]

for (let i = 0; i <= 5000; i++) {
  console.log(i);
}

const endTime = performance.now(); // [!code highlight]

console.log(`This code took ${endTime - startTime}ms`); // [!code highlight]
```

The output will look similar to this:

```bash
This code took 8.351621000000002ms
```

### `console.time()` approach

For quick measurements, `console.time()` and `console.timeEnd()` provide a simpler alternative:

```js
console.time("task"); // [!code highlight]

for (let i = 0; i <= 5000; i++) {
  console.log(i);
}

console.timeEnd("task"); // [!code highlight]
```

The output will look similar to this:

```bash
[6.95ms] task
```

### Accuracy

<Callout type="warning">
  Results vary between runs. Warm up the code, repeat the measurement, and test
  realistic inputs before drawing conclusions.
</Callout>
